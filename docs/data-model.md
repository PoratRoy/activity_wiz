# Data model

There is one Cloudflare D1 database (binding `DB`) with exactly **5 tables**, defined with Drizzle in `src/lib/db/schema.ts`. Migrations are generated by `drizzle-kit generate` into `drizzle/` and applied with `wrangler d1 migrations apply`.

- IDs: `nanoid(10)` text, using a lowercase alphanumeric alphabet so they're URL-safe.
- Timestamps: `integer` Unix milliseconds.
- Nullable enum-like columns store the **exact Hebrew value** shown in the UI, except movement and type, which store their keys.

| `google_sub` | text, unique, not null | Google account ID; the identity key |

| `last_seen_message_id` | text, nullable | ID of the last broadcast message the user dismissed. Any other current ID means unseen |
| `created_at` | integer, not null | |

## `public_category`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | |
| `title` | text, not null | |
| `position` | integer, not null, default 0 | Admin-set display order; sort ascending. New categories get max + 1. Migration `0001` backfilled existing rows oldest first |
| `key` | text, nullable, unique | English name, required when creating. Picks the artwork `public/library/<key>.webp` (case-insensitive, names listed in `src/data/libraryImages.json`); no match shows the shared default. Null only for older categories that were never given one. Migration `0003` renamed it from `image` |
| `created_at` | integer, not null | Tie-breaker after `position` |

## `public_activity`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | |
| `category_id` | text, not null, FK → `public_category.id` on delete cascade | Index on `(category_id, created_at)` |
| `title` | text, not null | |
| `body_md` | text, not null | |
| `type`, `subject`, `place`, `duration` | text, not null | Same values as `activity` |
| `equipment`, `teams`, `shabbat`, `notes` | text, nullable | Same values as `activity` |
| `age` | text, not null, default `לא משנה` | Which ages it fits: `לא משנה`, `שכבה צעירה` or `שכבה בוגרת` |
| `position` | integer, not null, default 0 | Admin-set order within the category; sort ascending. A new activity, or one moved to another category, gets min − 1 so it shows first. Migration `0010` backfilled existing rows newest first |
| `created_at` | integer, not null | Tie-breaker after `position`, descending |

`public_activity` has the same content columns as `activity`. A library copy copies every one of them. `age` is library-only: it is not a content column and is not copied.

D1 enforces foreign keys, so deleting a category cascades to its activities. Slugs are not stored: URLs are `slugify(title)-id`, and only the ID is used for lookup.

## `broadcast_message`

The admin's message to signed-in users (`/admin/message`). At most one row: every send deletes it and inserts a new row with a new ID, so every user sees the new message once.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | New on every send |
| `title` | text, not null | Up to 80 characters |
| `body` | text, not null | Plain text with line breaks, up to 1000 characters |
| `with_form` | integer (boolean), not null, default false | Show a feedback field that is emailed to the contact address |
| `sent_at` | integer, not null | |

## Not in D1

| Data | Where | Shape |
| --- | --- | --- |
| Rate limit | Durable Object `RateLimiter`, one instance per key: `u:{userId}` / `g:{guestId}` (30-second window), `ip:gen:{ip}` (attempts per minute), `add:{userId}` (copies and claims), `save:{userId}` (autosave) | `lastAt` for single-window keys; `window: { start, n }` for counted keys; `expiresAt` on both. An alarm deletes the object's storage when the window ends. |
| Guest identity + trial | Signed HttpOnly cookie `aw_guest` (HMAC with `GUEST_COOKIE_SECRET`) | `{ id, trialStart? }`. `trialStart` is set at the first generation. Max-age 1 year. |
| Group (cache) | `localStorage['aw.group']` | `{ movement, grade, groupSize, gender }` |
| Guest draft activity | `localStorage['aw.draft']` | `{ title, bodyMd, type, subject, place, duration, equipment?, teams?, shabbat?, notes?, createdAt }` |
| In-progress activity form | `sessionStorage['aw.activityForm']` | The activity page's field values |
| Pending generation request | `sessionStorage['aw.request']` | `{ group, activity }` |

## Core queries (`src/lib/db/queries.ts`)

- `upsertUserByGoogleSub({ sub, email, name, image })` → `id`
- `getUser(id)`, `updateGroup(userId, group)`
- `listActivities(userId)`: `id, title, created_at`, ordered by `created_at desc`
- `getActivity(id, userId)`: `null` if the activity doesn't exist or isn't owned by that user
- `insertActivity(userId, data)`, `updateActivity(id, userId, { title, bodyMd })` (sets `updated_at`), `deleteActivity(id, userId)`
- `getBroadcastMessage()`, `sendBroadcastMessage({ title, body, withForm })` (replaces the row with a new ID), `getUnseenBroadcastMessage(userId)`, `markBroadcastMessageSeen(userId, messageId)`, `broadcastMessageStats(messageId)` → `{ seen, total }`
- `listCategories()`, `getCategory(id)`, `insertCategory(title)`, `deleteCategory(id)`
- `listPublicActivities(categoryId)` (by `position`), `setPublicActivityOrder(categoryId, ids)`, `getPublicActivity(id)`, `insertPublicActivity(...)`, `deletePublicActivity(id)`, `countPublicActivities(categoryId)`

Every write that touches a personal activity includes `user_id = ?` in its `WHERE` clause.
