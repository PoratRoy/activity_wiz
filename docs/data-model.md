# Data model

There is one Cloudflare D1 database (binding `DB`) with exactly **4 tables**, defined with Drizzle in `src/lib/db/schema.ts`. Migrations are generated by `drizzle-kit generate` into `drizzle/` and applied with `wrangler d1 migrations apply`.

- IDs: `nanoid(10)` text, using a lowercase alphanumeric alphabet so they're URL-safe.
- Timestamps: `integer` Unix milliseconds.
- Nullable enum-like columns store the **exact Hebrew value** shown in the UI, except movement and type, which store their keys.

## `users`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | nanoid |
| `google_sub` | text, unique, not null | Google account ID; the identity key |
| `email` | text, not null | Updated on every sign-in |
| `name` | text | |
| `image` | text | Google avatar URL |
| `movement` | text, nullable | Movement key, e.g. `scout` |
| `grade` | text, nullable | e.g. `כיתה ה׳` |
| `group_size` | text, nullable | e.g. `10-20` |
| `gender` | text, nullable | `בנים` / `בנות` / `מעורב` |
| `created_at` | integer, not null | |

## `public_category`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | |
| `title` | text, not null | |
| `position` | integer, not null, default 0 | Admin-set display order; sort ascending. New categories get max + 1. Migration `0001` backfilled existing rows oldest first |
| `key` | text, nullable, unique | English name, required when creating. Picks the artwork `public/library/<key>.webp` (case-insensitive, names listed in `src/data/libraryImages.json`); no match shows the shared default. Null only for older categories that were never given one. Migration `0003` renamed it from `image` |
| `created_at` | integer, not null | Tie-breaker after `position` |

## `public_activity`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | text PK | |
| `category_id` | text, not null, FK → `public_category.id` on delete cascade | Index on `(category_id, created_at)` |
| `title` | text, not null | |
| `body_md` | text, not null | |
| `type`, `subject`, `place`, `duration` | text, not null | Same values as `activity` |
| `equipment`, `teams`, `shabbat`, `notes` | text, nullable | Same values as `activity` |
| `created_at` | integer, not null | Sort descending |

`public_activity` has the same content columns as `activity`. A library copy copies every one of them.

D1 enforces foreign keys, so deleting a category cascades to its activities. Slugs are not stored: URLs are `slugify(title)-id`, and only the ID is used for lookup.

## Not in D1

| Data | Where | Shape |
| --- | --- | --- |
| Rate limit | Durable Object `RateLimiter`, one instance per key (`u:{userId}` or `g:{guestId}`) | `lastAt` in DO storage |
| Guest identity + trial | Signed HttpOnly cookie `aw_guest` (HMAC with `GUEST_COOKIE_SECRET`) | `{ id, trialStart? }`. `trialStart` is set at the first generation. Max-age 1 year. |
| Group (cache) | `localStorage['aw.group']` | `{ movement, grade, groupSize, gender }` |
| Guest draft activity | `localStorage['aw.draft']` | `{ title, bodyMd, type, subject, place, duration, equipment?, teams?, shabbat?, notes?, createdAt }` |
| In-progress activity form | `sessionStorage['aw.activityForm']` | The activity page's field values |
| Pending generation request | `sessionStorage['aw.request']` | `{ group, activity }` |

## Core queries (`src/lib/db/queries.ts`)

- `upsertUserByGoogleSub({ sub, email, name, image })` → `id`
- `getUser(id)`, `updateGroup(userId, group)`
- `listActivities(userId)`: `id, title, created_at`, ordered by `created_at desc`
- `getActivity(id, userId)`: `null` if the activity doesn't exist or isn't owned by that user
- `insertActivity(userId, data)`, `updateActivity(id, userId, { title, bodyMd })` (sets `updated_at`), `deleteActivity(id, userId)`
- `listCategories()`, `getCategory(id)`, `insertCategory(title)`, `deleteCategory(id)`
- `listPublicActivities(categoryId)`, `getPublicActivity(id)`, `insertPublicActivity(...)`, `deletePublicActivity(id)`, `countPublicActivities(categoryId)`

Every write that touches a personal activity includes `user_id = ?` in its `WHERE` clause.
